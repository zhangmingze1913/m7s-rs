# 压力测试记录（单节点）

Date: 2026-11-17

## 环境

- Windows，release 二进制
- 单机客户端 `scripts/load_test.cjs`
- 服务端 `--demo`，单流 `live/test`
- 客户端临时端口默认 49152-65535（16384）

## 结果

| 目标 | 结果 | 耗时 | 备注 |
|---|---|---|---|
| 10,000 | **10000/10000** | 16.98s | 已验证 |
| 20,000 | **15907/20000** | 18.61s | 约 16K 后失败 |
| 50,000 | **16869/50000** | 24.78s | 放宽端口到 55K + backlog 65535 后仍约 16.8K |

服务端在 20K 测试后 RSS 16.7MB（连接释放），累计 CPU 18.1s；
50K 测试后 CPU 32.2s。

## 分析

单机客户端在约 **16K–17K 并发 TCP 连接**附近达到上限：

- 默认动态端口 16384；
- 放宽到 55000 后仍只有 ~16.8K 成功；
- 说明瓶颈在单机 socket/accept/事件循环，而非服务端协议错误；
- 因此 **100K / 1M 无法用单机客户端验证**。

## 结论

```text
✅ 10K 单节点通过
⚠️ 20K/50K 单机客户端约 16-17K 上限
❌ 100K / 1M 未验证（需分布式压测机）
```

100K/1M 需要：

- 多台压测机，每台 ≤10K 连接；
- 或多源 IP / 多网卡；
- 服务端多节点分流。

未把 100K/1M 标为完成。
