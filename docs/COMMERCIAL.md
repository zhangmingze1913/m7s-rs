# 商业化与替换评估

## 1. 产品定位

对标 Monibuca 的商业流媒体引擎，必须同时满足：

- 协议完整性与互操作性；
- 稳定性/性能/SLA；
- 安全与合规；
- 可运维、可扩展、可支持；
- 明确许可与知识产权边界。

仅“功能列表相同”不构成商业替换。

## 2. 商业化门槛

| 维度 | 要求 |
|---|---|
| 协议 | RTMP/HTTP-FLV/HLS/RTSP/WebRTC/SRT/GB28181/WebTransport 全互通 |
| 性能 | 单节点 10k 并发流、P99 延迟达标、72h 浸泡 |
| 可靠 | 多活、故障切换、灰度、回滚、数据一致性 |
| 安全 | TLS/mTLS、鉴权、审计、漏洞响应、渗透测试 |
| 运维 | 指标、日志、追踪、告警、K8s/Helm、备份 |
| 支持 | SLA、工单、版本维护、热修复 |
| 法务 | 许可、专利、出口/隐私合规 |

## 3. 许可策略

- 本仓库 MIT；可闭源分发/商业集成。
- Monibuca v5 为 AGPL，v6 闭源；不得复制其代码/资源。
- 若引入 FFmpeg/GStreamer，需评估 LGPL/GPL 与动态链接合规。
- WebRTC/SRT 等第三方库逐一做许可证清单（SBOM）。

## 4. 交付形态

- 单机二进制 / Docker / Helm Chart
- Admin + HTTP API + Web SDK
- 边缘节点轻量包
- 企业版：集群管理、录制、转码、审计、SLA

## 5. 商业化路线

1. **技术 PoC**：Phase 0/1，单机 HLS + 录制 + Admin。
2. **客户试点**：RTMP/HLS/HTTP-FLV，10–100 路。
3. **生产版本**：集群、QUIC、监控、安全、压测。
4. **行业版本**：GB28181/WebRTC/SRT，按场景打包。
5. **商业替换**：迁移工具、兼容性报告、SLA、备灾演练。

## 6. 不可承诺项

- 一次会话完成全部协议；
- 未压测即承诺 10k 流；
- 未做安全评估即承诺企业级安全；
- 未做互操作测试即承诺“完全兼容 Monibuca”；
- 未明确许可即商业分发第三方代码。

## 7. 建议下一步

批准 Phase 1（HLS + 录制 + Admin + TLS/鉴权 + 指标），以 6–8 周为交付周期，先形成可售卖的 RTMP/HLS 产品，再启动 WebRTC/GB28181 并行研发。
