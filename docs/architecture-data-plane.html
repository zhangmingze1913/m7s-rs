m7s-rs 数据面 · 零拷贝分发路径

Ingest → Stream::push → RingBuffer → Dispatcher → 有界订阅通道 → Egress
INGEST

协议适配

RTMP · RTSP · SRT
WHIP · WebTransport
GB28181 · ONVIF(控制)
解复用为统一 FlvTag { type, ts, data }；时间戳单调化。
→
STREAM

Stream::push()

Arc<FlvTag> 共享
bytes / subscribers 原子计数
config / metadata 缓存
GOP cache（新订阅者回放）
按 app/name 进入 StreamManager 的流注册表。
→
RING

RingBuffer

lock-free SPMC
ArcSwap / 原子序号
fixed capacity
发布者不等待慢订阅者；读取端按自己的序号推进。
→
FAN-OUT

Dispatcher

per-stream 单读广播
ArcSwap<Vec<Sub>>
DispatcherPool（按 key 分片）
一次 push，对 N 个订阅者 try_send(Arc clone)。
→
BACKPRESSURE

订阅通道

bounded 150
full → drop + counter
closed → 取消订阅
慢订阅者丢帧，不反压发布者；m7s_dispatch_dropped_total 可观测。
→
EGRESS

出口任务

HTTP-FLV · HLS TS/LL · fMP4
RTSP TCP/UDP · WHEP RTP
MP4 / Record · Cluster relay
每个连接独立的 reader task；WHEP/HLS/RTSP 通过 tap 获取流。
新订阅者
先取 GOP/config backlog（cache_snapshot / tag_reader）， 再并入 Dispatcher 实时通道，避免黑屏/花屏。
零拷贝边界
Arc<FlvTag> 在 Stream、Ring、Dispatcher、各订阅者之间共享； 只有协议出口需要重打包时才复制 payload。
可观测性
每流 subscribers/bytes/latency；全局 streams/subscribers； drop 计数；HTTP /metrics 输出 Prometheus 文本。
