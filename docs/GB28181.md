# GB28181 当前实现

## 已实现

- UDP SIP 服务端（默认 `0.0.0.0:5060`）；
- `REGISTER`：
  - 解析 `From/To/Via/Call-ID/CSeq/Contact/Expires`；
  - 从 `sip:设备ID@域` 提取设备 ID；
  - 设备注册表；
  - 返回 `SIP/2.0 200 OK`，带 Contact/Expires/Server；
- `MESSAGE`：返回 `200 OK`（心跳/保活基础）；
- Digest 鉴权（MD5 + qop=auth）：动态 nonce、60 秒有效、单次使用，校验 REGISTER；
- 单元测试：SIP URI 解析、真实 UDP REGISTER。

## 未实现

- Digest 鉴权（401/WWW-Authenticate）；
- 目录查询 `Catalog` XML；
- `INVITE/BYE`、SDP、RTP/PS 收流；
- 语音广播、历史回放、云台控制；
- TCP SIP、TLS、级联。

因此当前是 **GB28181 SIP 注册/心跳第一步**，不是完整 GB28181 平台。

## GB28181 DeviceControl/PTZ signaling

- MESSAGE `<CmdType>DeviceControl</CmdType>` is parsed;
- `<PTZCmd>` stored in `GbState`; `last_ptz()` exposes it;
- SIP 200 returned to the device.

Test: `tests::ptz_control_records_command`.
## INVITE Playback signaling

INVITE bodies with `s=Playback`/`S=Playback` are classified as `Playback`
and recorded in `GbState.last_invite()`; 200 OK/SDP behavior unchanged.

Test: `tests::invite_playback_records_mode`.

This is signaling only: PS/RTP playback media and file seeking are still
not implemented.
## PS muxer / RTP packetizer (playback building block)

`m7s-plugin-gb28181::ps`:

- `PsMuxer::pack(video_pts, video, audio_pts, audio)` -> MPEG-PS
  (`00 00 01 BA`, system header, PES 0xE0/0xC0, PTS).
- `PsMuxer::rtp(timestamp, ps)` -> RTP packets (PT 96, marker on last,
  MTU 1400, SSRC).

Tests: `ps::tests::pack_has_ps_and_pes`, `rtp_fragments_and_marks_last`.

Not yet wired to SIP Playback sessions or a recording source.
## Playback target binding

Playback INVITE now parses SDP `c=IN IP4` and `m=video <port>` and stores
the target (`GbState::playback_target()`). `ps::send_tags` can transmit
PS/RTP to a UDP target; verified with a local UDP receiver.

Test: `tests::invite_playback_records_target`, `ps::send_tests::sends_ps_over_udp`.
Still missing: recording file source and automatic send on INVITE.
## FLV playback source + auto send

- `ps::play_flv_file(path, socket, target)` reads an FLV recording and sends
  PS/RTP to the target (tested with a local UDP receiver).
- Playback INVITE spawns this automatically when `M7S_GB_PLAYBACK_FILE` is set.

Tests: `ps::file_tests::plays_flv_file`, `invite_playback_records_target`.
## Playback seek / speed

`ps::play_flv_file_range(path, socket, target, start_ms, speed)`:

- skips tags before `start_ms`;
- paces by timestamp delta / speed.

INVITE auto playback reads `M7S_GB_PLAYBACK_START_MS` and
`M7S_GB_PLAYBACK_SPEED`.

Test: `ps::range_tests::start_filter`.
## Playback pause/resume

`ps::play_flv_file_controlled(..., paused: Arc<AtomicBool>)` blocks between
tags while paused and resumes when cleared.

Test: `ps::pause_tests::pause_blocks_send` (no packet while paused, packets
after resume).

## SIP PlaybackControl / RecordInfo (2026-11-21)

`MESSAGE` handling now covers:

- `<CmdType>PlaybackControl</CmdType>`：
  - `PAUSE` -> `PlaybackState.paused`；
  - `Speed` -> `PlaybackState.speed`；
  - `Range` -> `PlaybackState.range`；
  - `GbState::playback()` 可查询。
- `<CmdType>RecordInfo</CmdType>`：返回 `RecordInfo` 响应（当前空列表，
  `RecordList Num="0"`），用于设备侧录像查询握手。

Tests:

```text
tests::playback_control_updates_state
tests::record_info_returns_empty_list
```

仍缺：真实设备 Catalog/RecordInfo 内容、录像写入、真实 PTZ 云台闭环。
